1. Datos para Tarjetas de Resumen (KPI Cards)
Son datos crudos de 1 solo valor. No necesitan un gráfico, sino una tarjeta bonita con un número grande al inicio de tu Dashboard.

Endpoint Experiencia: promedio (ej. 3.2 años), mediana, moda, tasa_entry_level.
Endpoint Empresa: total_empresas_identificadas.
Endpoint Tech-Stack: promedio_techs_por_oferta.
Endpoint Timing: ultimas_24h (ofertas nuevas), dia_pico_absoluto.
Endpoint Compatibilidad: tasa_descarte_sub_40.
2. Datos para Gráficos de Anillo (Donut Charts) o Tarta
Ideales para mostrar cómo se divide un total en proporciones o porcentajes.

Endpoint Origen: distribucion_porcentaje (ej. LinkedIn 60%, GetOnBoard 30%, etc.).
Endpoint English: proporcion_general (Gráfico simple: 65% Requiere Inglés / 35% No Requiere).
Endpoint Empresa: analisis_larga_cola (Empresas identificadas con 1 oferta vs Empresas recurrentes).
3. Datos para Gráficos de Barras Horizontales (Bar Lists)
Perfectos para rankings o Top 10/Top 15.

Endpoint Tech-Stack: popularidad_top_15. Tremor tiene un componente llamado BarList que es literalmente una lista hacia abajo con una pequeña barra de progreso. Ideal para ver que Python tiene 150 menciones, SQL 120, etc.
Endpoint Empresa: top_10_empresas (Las empresas que más publican).
Endpoint English: top_tecnologias_bilingues.
4. Datos para Gráficos de Barras Verticales o Áreas (BarChart / AreaChart)
Útiles para distribuciones de tiempo o de volumen.

Endpoint Timing: frecuencia_por_hora y volumen_por_dia. Esto va directo a un gráfico de barras para ver los "picos" de publicación.
Endpoint Experiencia: distribucion_niveles (Trainee, Junior, Semi-Senior, Senior). Un gráfico de barras te permite ver claramente dónde está el grueso del mercado.
Endpoint Compatibilidad: desempeno_por_origen (Comparar qué portal tiene mejores scores).
5. Datos para Comparativas (Gráficos de Barras Agrupadas)
Cuando cruzas dos variables.

Endpoint English: impacto_experiencia_anios (Barra A: Experiencia promedio exigida CON inglés / Barra B: SIN inglés).
Endpoint English: impacto_compatibilidad (Score con inglés vs Score sin inglés).
